# Problem 8

Write a program to open a file in read-only mode, read line by line and display each line as it is read. Close the file when end of file is reached.

## Program

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    int fd;
    char ch;

    // Open the file in read-only mode
    fd = open("input.txt", O_RDONLY);

    if (fd == -1) {
        perror("open");
        return 1;
    }

    // Read the file character by character
    while (read(fd, &ch, 1) > 0) {

        // Display the character
        write(STDOUT_FILENO, &ch, 1);

        // Newline indicates the end of a line
        if (ch == '\n') {
            // Current line has been displayed
        }
    }

    // Close the file after reaching EOF
    close(fd);

    return 0;
}
```

## Explanation

First, the file is opened in read-only mode:

```c
fd = open("input.txt", O_RDONLY);
```

`O_RDONLY` means that the file can only be read.

The program then reads one character at a time:

```c
read(fd, &ch, 1)
```

The `read()` system call returns:

* A positive value → data was successfully read.
* `0` → End of File (EOF) has been reached.
* `-1` → An error occurred.

Therefore, this loop:

```c
while (read(fd, &ch, 1) > 0)
```

continues until EOF is reached.

Each character is displayed using:

```c
write(STDOUT_FILENO, &ch, 1);
```

When the character is `'\n'`, the current line has ended.

After EOF is reached, the file is closed:

```c
close(fd);
```

The program opens `input.txt` in read-only mode, reads its contents sequentially using the `read()` system call, displays them using `write()`, and closes the file after reaching EOF.
