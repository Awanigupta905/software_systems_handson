**Problem 11: Duplicate File Descriptor Using dup(), dup2() and fcntl()**

### Aim

Write a program to open a file, duplicate the file descriptor, and append the file using both the original and duplicated descriptors.

The program should demonstrate:

a. `dup()`
b. `dup2()`
c. `fcntl()`

After writing using both descriptors, check whether the file is updated properly.

### Concept

A **file descriptor** is an integer used by a process to identify an open file.

The `dup()`, `dup2()`, and `fcntl()` system calls can be used to duplicate a file descriptor.

The duplicated descriptors refer to the same open file description.

### 1. dup()

Syntax:

```c
newfd = dup(oldfd);
```

`dup()` creates a new file descriptor that refers to the same open file as `oldfd`.

Example:

```text
fd = 3
dup(fd) = 4
```

Both `3` and `4` refer to the same file.

### 2. dup2()

Syntax:

```c
newfd = dup2(oldfd, newfd);
```

`dup2()` duplicates `oldfd` into a specific file descriptor number.

For example:

```c
dup2(fd, 10);
```

makes file descriptor `10` refer to the same open file as `fd`.

### 3. fcntl()

Syntax:

```c
newfd = fcntl(oldfd, F_DUPFD, minimum_fd);
```

`fcntl()` with `F_DUPFD` creates a duplicate file descriptor whose value is greater than or equal to the specified minimum descriptor.

For example:

```c
fcntl(fd, F_DUPFD, 10);
```

creates a new descriptor with a value of at least `10`.

### Why O_APPEND is Used

The file is opened using:

```c
O_WRONLY | O_CREAT | O_APPEND
```

`O_APPEND` ensures that every write is performed at the end of the file.

Therefore, data written using both the original and duplicated descriptors is appended to the file.

### Program

The program is stored in `problem11.c`.

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    int fd, fd_dup, fd_dup2, fd_fcntl;

    // Open file in append mode
    fd = open("file11.txt", O_WRONLY | O_CREAT | O_APPEND, 0644);

    if (fd == -1) {
        perror("open");
        return 1;
    }

    // ------------------------------------------------
    // a. Duplicate using dup()
    // ------------------------------------------------
    fd_dup = dup(fd);

    if (fd_dup == -1) {
        perror("dup");
        close(fd);
        return 1;
    }

    write(fd, "Written using original fd\n", 26);
    write(fd_dup, "Written using dup fd\n", 21);

    printf("Original FD: %d\n", fd);
    printf("dup() FD   : %d\n", fd_dup);

    close(fd_dup);

    // ------------------------------------------------
    // b. Duplicate using dup2()
    // ------------------------------------------------
    fd_dup2 = dup2(fd, 10);

    if (fd_dup2 == -1) {
        perror("dup2");
        close(fd);
        return 1;
    }

    write(fd, "Written using original fd again\n", 33);
    write(fd_dup2, "Written using dup2 fd\n", 22);

    printf("dup2() FD  : %d\n", fd_dup2);

    close(fd_dup2);

    // ------------------------------------------------
    // c. Duplicate using fcntl()
    // ------------------------------------------------
    fd_fcntl = fcntl(fd, F_DUPFD, 10);

    if (fd_fcntl == -1) {
        perror("fcntl");
        close(fd);
        return 1;
    }

    write(fd, "Written using original fd again\n", 33);
    write(fd_fcntl, "Written using fcntl fd\n", 24);

    printf("fcntl() FD : %d\n", fd_fcntl);

    close(fd_fcntl);
    close(fd);

    return 0;
}
```

### Important Observation

The original and duplicated file descriptors refer to the same open file description.

Therefore:

```text
Original FD
     |
     v
  Open File Description
     |
     +----> File
     |
     ^
     |
Duplicated FD
```

For `dup()`:

```text
fd = 3
dup(fd) = 4
```

For `dup2()`:

```text
fd = 3
dup2(fd, 10) = 10
```

For `fcntl()`:

```text
fd = 3
fcntl(fd, F_DUPFD, 10)
```

returns a descriptor greater than or equal to `10`.

### Difference Between dup(), dup2() and fcntl()

| Function         | Purpose                                                |
| ---------------- | ------------------------------------------------------ |
| `dup()`          | Creates a duplicate using the lowest available FD      |
| `dup2()`         | Creates a duplicate at a specified FD                  |
| `fcntl(F_DUPFD)` | Creates a duplicate at or above a specified minimum FD |
