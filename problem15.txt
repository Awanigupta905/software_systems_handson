Problem 15: Display Environmental Variables Using environ

Aim

Write a program to display the environmental variables of the user using the environ variable.

Concept

Environment variables are variables maintained by the operating system that contain information about the user's environment.

Examples of environment variables are:

PATH
HOME
USER
SHELL
PWD

In C, the environment variables can be accessed using the external variable:

extern char **environ;

The environ variable is an array of strings.

Each string contains an environment variable in the following format:

NAME=VALUE

For example:

PATH=/usr/local/bin:/usr/bin:/bin
HOME=/home/awani
USER=awani

Program

The program is stored in problem15.c.

#include <stdio.h>

extern char **environ;

int main()
{
    char **env = environ;

    while (*env != NULL)
    {
        printf("%s\n", *env);
        env++;
    }

    return 0;
}


Explanation

1. Include the standard input/output header file

#include <stdio.h>

This header file is required for the printf() function.

2. Declare environ

extern char **environ;

The environ variable is provided by the operating system.

It is declared as:

char **environ

This means environ is a pointer to an array of character pointers.

Each element of the array points to a string containing one environment variable.

3. Create a pointer to environ

char **env = environ;

The pointer env is initialized with environ.

Now env points to the first environment variable.

For example:

env
 |
 v
"PATH=/usr/local/bin..."
"HOME=/home/awani"
"USER=awani"
...
NULL

4. Traverse all environment variables

while (*env != NULL)

The loop continues until the NULL pointer is reached.

Each environment variable is stored as a string, so:

*env

represents the current environment variable.

5. Display the environment variable

printf("%s\n", *env);

This prints the current environment variable.

For example:

PATH=/usr/local/bin:/usr/bin:/bin

6. Move to the next environment variable

env++;

This moves the pointer to the next environment variable.

The loop continues until all environment variables have been displayed.

7. End of program

return 0;

This indicates that the program completed successfully.


How environ Works

The environment variables are stored in an array of strings.

Conceptually, the structure looks like:

environ
   |
   v
+-----------------------------+
| "PATH=/usr/bin:..."         |
+-----------------------------+
| "HOME=/home/awani"          |
+-----------------------------+
| "USER=awani"                |
+-----------------------------+
| "SHELL=/bin/bash"           |
+-----------------------------+
| ...                         |
+-----------------------------+
| NULL                        |
+-----------------------------+

The program traverses this array one element at a time.

Important Point

The environment variables are system-dependent.

Therefore, the output may be different on different computers or for different users.


Difference Between environ and getenv()

environ:

extern char **environ;

is used to access and display all environment variables.

getenv():

getenv("PATH");

is used to retrieve the value of a specific environment variable.

For example:

char *path = getenv("PATH");

This retrieves only the PATH variable.

In this problem, environ is used because the requirement is to display the environment variables of the user.
