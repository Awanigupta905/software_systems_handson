**Problem 14: Find the Type of a File**

### Aim

Write a program to find the type of a file.

Requirements:

a. Input should be taken from the command line.
b. The program should be able to identify different types of files.

### Concept

Linux treats different objects as files.

Some common file types are:

* Regular file
* Directory
* Symbolic link
* FIFO / Named pipe
* Socket
* Character device
* Block device

The `lstat()` system call is used to obtain information about a file.

The file type can then be identified using macros provided in `<sys/stat.h>`.

### File Type Macros

| Macro        | File Type         |
| ------------ | ----------------- |
| `S_ISREG()`  | Regular file      |
| `S_ISDIR()`  | Directory         |
| `S_ISLNK()`  | Symbolic link     |
| `S_ISFIFO()` | FIFO / Named pipe |
| `S_ISSOCK()` | Socket            |
| `S_ISCHR()`  | Character device  |
| `S_ISBLK()`  | Block device      |

### Command-Line Argument

The filename is taken from the command line.

For example:

```bash
./problem14 test.txt
```

Here:

* `argv[0]` → program name
* `argv[1]` → filename supplied by the user

Therefore:

```c
argv[1]
```

contains the file whose type we want to identify.

### Program

The program is stored in `problem14.c`.

```c
#include <stdio.h>
#include <sys/stat.h>
#include <unistd.h>

int main(int argc, char *argv[]) {
    struct stat file;

    // Check command-line argument
    if (argc != 2) {
        printf("Usage: %s <filename>\n", argv[0]);
        return 1;
    }

    // Get file information
    if (lstat(argv[1], &file) == -1) {
        perror("lstat");
        return 1;
    }

    // Identify file type
    if (S_ISREG(file.st_mode)) {
        printf("%s is a Regular File.\n", argv[1]);
    }
    else if (S_ISDIR(file.st_mode)) {
        printf("%s is a Directory.\n", argv[1]);
    }
    else if (S_ISLNK(file.st_mode)) {
        printf("%s is a Symbolic Link.\n", argv[1]);
    }
    else if (S_ISFIFO(file.st_mode)) {
        printf("%s is a FIFO (Named Pipe).\n", argv[1]);
    }
    else if (S_ISSOCK(file.st_mode)) {
        printf("%s is a Socket.\n", argv[1]);
    }
    else if (S_ISCHR(file.st_mode)) {
        printf("%s is a Character Device.\n", argv[1]);
    }
    else if (S_ISBLK(file.st_mode)) {
        printf("%s is a Block Device.\n", argv[1]);
    }
    else {
        printf("%s is of an Unknown File Type.\n", argv[1]);
    }

    return 0;
}
```

### Explanation

#### 1. Include required header files

```c
#include <stdio.h>
#include <sys/stat.h>
#include <unistd.h>
```

`sys/stat.h` provides `struct stat`, `lstat()`, and the file-type macros.

#### 2. Take command-line arguments

```c
int main(int argc, char *argv[])
```

`argc` contains the number of command-line arguments.

`argv` contains the actual arguments.

For:

```bash
./problem14 test.txt
```

we have:

```text
argc = 2
argv[0] = ./problem14
argv[1] = test.txt
```

#### 3. Check the number of arguments

```c
if (argc != 2)
```

The program expects exactly one filename.

If the user runs:

```bash
./problem14
```

the program displays:

```text
Usage: ./problem14 <filename>
```

#### 4. Get file information

```c
lstat(argv[1], &file);
```

`lstat()` stores information about the specified file in the `struct stat` variable.

#### 5. Check the file type

For a regular file:

```c
S_ISREG(file.st_mode)
```

For a directory:

```c
S_ISDIR(file.st_mode)
```

For a symbolic link:

```c
S_ISLNK(file.st_mode)
```

For a FIFO:

```c
S_ISFIFO(file.st_mode)
```

Similarly, `S_ISSOCK()`, `S_ISCHR()`, and `S_ISBLK()` check for sockets, character devices, and block devices.

### Test 1: Regular File

Create a file:

```bash
echo "Hello Linux" > test.txt
```

Run:

```bash
./problem14 test.txt
```

Output:

```text
test.txt is a Regular File.
```

### Test 2: Directory

Run:

```bash
./problem14 .
```

Output:

```text
. is a Directory.
```

You can also test:

```bash
./problem14 /tmp
```

### Test 3: Symbolic Link

Create a symbolic link:

```bash
ln -s test.txt softlink
```

Run:

```bash
./problem14 softlink
```

Output:

```text
softlink is a Symbolic Link.
```

### Test 4: FIFO

Create a FIFO:

```bash
mkfifo myfifo
```

Run:

```bash
./problem14 myfifo
```

Output:

```text
myfifo is a FIFO (Named Pipe).
```

### Test 5: Invalid File

Run:

```bash
./problem14 abc.txt
```

If the file doesn't exist, you will get something similar to:

```text
lstat: No such file or directory
```

### Important Point

We use `lstat()` instead of `stat()` because `lstat()` identifies a symbolic link as a **symbolic link itself**, rather than following the link to the file it points to.
