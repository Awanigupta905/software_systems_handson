# Problem 3

Write a program to create a file and print the file descriptor value using the `creat()` system call.

## Program

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    int fd;

    fd = creat("newfile.txt", 0644);

    if (fd == -1) {
        perror("creat");
        return 1;
    }

    printf("File created successfully.\n");
    printf("File Descriptor: %d\n", fd);

    close(fd);

    return 0;
}
```

## Compilation

```bash
gcc problem3.c -o problem3
```

## Execution

```bash
./problem3
```

### Expected Output

```text
File created successfully.
File Descriptor: 3
```

The exact file descriptor value may vary depending on which file descriptors are already open.

The program creates a file named `newfile.txt` with permission `0644` and prints the file descriptor returned by the `creat()` system call.

Finally, `close(fd)` closes the file descriptor.
