# Problem 7

Write a program to copy `file1` into `file2`.

This program performs the equivalent operation of:

```bash
cp file1 file2
```

## Program

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    int fd1, fd2;
    char buffer[1024];
    int n;

    // Open file1 for reading
    fd1 = open("file1", O_RDONLY);

    if (fd1 == -1) {
        perror("file1");
        return 1;
    }

    // Create file2 for writing
    fd2 = open("file2", O_WRONLY | O_CREAT | O_TRUNC, 0644);

    if (fd2 == -1) {
        perror("file2");
        close(fd1);
        return 1;
    }

    // Read from file1 and write to file2
    while ((n = read(fd1, buffer, sizeof(buffer))) > 0) {
        write(fd2, buffer, n);
    }

    printf("File copied successfully.\n");

    close(fd1);
    close(fd2);

    return 0;
}
```

## Explanation

First, `file1` is opened in read-only mode:

```c
fd1 = open("file1", O_RDONLY);
```

Then `file2` is created/opened for writing:

```c
fd2 = open("file2", O_WRONLY | O_CREAT | O_TRUNC, 0644);
```

The program repeatedly reads data from `file1`:

```c
read(fd1, buffer, sizeof(buffer))
```

and writes the data into `file2`:

```c
write(fd2, buffer, n)
```

The loop continues until the entire contents of `file1` have been copied.

Finally, both file descriptors are closed using `close()`.

## Testing

First create `file1`:

```bash
echo "This is the content of file1." > file1
```

Compile the program:

```bash
gcc problem7.c -o problem7
```

Run it:

```bash
./problem7
```

Expected output:

```text
File copied successfully.
```

Check the contents:

```bash
cat file1
cat file2
```

Both files should contain:

```text
This is the content of file1.
```

## Conclusion

The program copies the contents of `file1` into `file2` by opening the files and using `read()` and `write()` system calls. It performs the same basic operation as the Linux command:

```bash
cp file1 file2
```
